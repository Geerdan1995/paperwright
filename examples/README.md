# 生产战例（production notes）

Paperwright 的每条规则都来自真实出书。三次代表性战例的项目结构与决策记录：

## 1. 企业白皮书（全一册 430 页）
开源文档站（VitePress）→ 单卷。经验起源：目录断页三规则、前件命名页、12pt 起印。

## 2. 技术专著（全一册 393 页）
mkdocs 书 → 单卷。经验：编译期公式渲染＋货币启发式、章末注转制、章号从导航解析。

## 3. 产品沉思录存档（六卷 2,801 页）
477 篇正文＋155 存档＋312 站外转载 → 六卷。经验：附件跟首引文章、辑内索引（丁方案）、
去重要用 bigram 包含度（shingle 指纹抓不住精编 reprint）、失败台账印进书里。

## 4. 北大课程实录（全一册 354 页）
Astro 站 12 篇逐字转写 → 单卷。经验：paged.js 专业模式首战、方案C 纸面细框封面、
box-sizing:border-box 溢出坑、标题锚点 # 清洗、字号阶梯裁决（1.85 行距／0.6em 段距）。

> 这些项目的本地副本不在本仓库（含个人路径与书稿内容）；结构可参照
> templates/README.md 的标准链路。欢迎用 Paperwright 出书后回来分享战例。
