# 内容清洗与查重（清洗配方 · 链接政策 · 去重方法论 · 编辑决策层）

## 查重：别信单一指纹

- **字符 shingle 指纹（k=24）抓不住"精编 reprint"**：实测萧逸案——文章是存档的精编版，整段逐字同文却被判 9% 重合（插入式增删改打断长 shingle）。
- 正确姿势三层递进：**bigram 包含度**（k=2，对插入式编辑免疫；用"罕见 bigram"（df≤3）定位最相似文章再精测，155×477 全对比也可行）＋**标题对撞**（归一化后互相包含）＋**实读抽样**（可疑对逐对读开头判断关系：原始版 vs 精编版／同人物不同侧面／资料汇编 vs 随笔／完全无关）。
- **完整性结论不许说满**：不说"100% 无重复/无遗漏"，说"经 X 方法检测＋抽样实读，重合度分布为…"。

## 编辑决策层（所有范围类决定归用户）

动工前必须问清（一次列全，别挤牙膏）：收录范围（全量/筛选/要不要站内存档或外链内容）／**语种（作者看不懂英文，外文原文默认不收）**／图片进书否／排序（时间倒序/站点顺序/最具体主题优先）／多主题归属（单归属＋索引 vs 重复出现 vs 混合索引）／分卷方式／书名（**贴用户原话用词**）。
**AskUserQuestion 没等到回答 ≠ 默许推荐项**——停下等。抓取类后台任务可并行跑，但"收录什么"类决定不能替作者做。

## 链接三条政策（印刷态）

| 链接类型 | 处理 | 例 |
|---|---|---|
| 站内文章 | 「《标题》」纯文字 | 站内互引 |
| 站内存档页 | 「〔存档｜标题〕」标记（不收录时只示存在；收录时附卷号「见第N卷」） | Notion 内页/旧刊 |
| 站外网页 | `span.elink` 样式文字，不印 URL | 推荐阅读 |
| 原文链接（篇尾） | 单独一行印「原文链接：域名」 | 出处标注 |

## "链接内容"收录判定

1. 正文信号词扫描（全文/完整版/原文在此/翻译自/详见）→ 内容依赖外链的短名单。
2. 站方自带存档（如 /n/ 引用页）优先于站外抓取——零反爬风险。
3. 短评型文章（站内 <2600 字）多半是摘要，原文才是内容——**收录与否问作者，语种尤其要问**。
4. 站外抓取按域名分桶定配方（见下），失败如实台账＋正文后注记，不装没有发生过。

## 标题锚点 #（印刷态必删）

静态站给每个标题挂悬停锚点：`<a class="anchor" href="#…"><span class="anchor-icon">#</span></a>`（markdown-it-anchor 及各框架变体，网页上 hover 才显示，印刷 PDF 恒显）。清洗两刀＋一兜底：①`class~anchor` 元素整体 decompose；②文本恰为 `#` 的 `<a>` decompose；③兜底扫 h3/h4 末尾残留 `#` 文本节点。验收：全文扫 `标题行以 # 结尾` 必须为 0。

## 站外抓取配方（fetch-external.cjs）

- Playwright 4 路并发；UA＋`addInitScript` stealth（webdriver/plugins/languages 覆写）；分域名等待与选择器：
  - 微信公众号：`#js_content`，`data-src` 图片，作者 `#js_name`；"环境异常"= 验证墙（记失败）
  - 知乎：`.Post-RichTextContainer`；headless 硬墙 403，API 也要登录——接受失败别恋战
  - 豆瓣：`#link-report .note / .review-content / .topic-content`
  - 通用：`article / main / .post-content` 降级 body
- 图片就地 `page.request.get` 落 `assets/img/ext-<hash>.img`（无扩展名 Chromium 按 magic bytes 渲染没问题）。
- 结果 `fetched/<hash>.json`（含清洗前 HTML＋imgs 映射）；失败也落盘。**总账从 fetched/*.json 重建**（`_ledger.json` 会被中断丢尾部）。
- 清洗四刀：标签级（script/nav/aside/header/footer… decompose）→ 类名黑名单（skip|nav|menu|share|subscribe… 且文本 <200 字，防误伤长正文）→ 文本黑名单（skip to content/sign in/subscribe/on this page）→ 转载标题重复的 h1/h2（归一化去标点后互相包含）。bs4 元素 `t.attrs` 可能为 None，取值前 `t.attrs or {}`。

## 多主题归属三法（用户选）

- 甲·最具体单归属：归成员最少的主题（并列取站点序）；大类辑名存实亡但分类干净。
- 乙·大类优先：贴站面数字（思维模型=140），尾部小类塌缩到 2–4 篇。
- 丁·甲＋辑内索引（作者实测选定）：文章只印一次，辑扉标「本卷 N 篇 · 全站 N 篇」，辑末双栏索引列其余成员（标题＋见第N卷，`columns:2` 小字点线）；零专属大类以纯索引辑进书。
